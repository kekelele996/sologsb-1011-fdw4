# LiveCaption Desk · 实时字幕纠错台

LiveCaption Desk 是面向直播字幕校对员的长时间值守工作台。字幕按时间顺序进入待确认区，确认后进入直播区；校对员可以快速处理标点、专有名词、发言人和数字，并在弱网或断线时继续工作。

## 功能

- 实时待确认队列：按时间和序号显示字幕，支持只看需处理内容或异常优先。
- 字幕编辑：修改正文、标点和数字；支持全角数字、中文数字及常见数字格式规范化。
- 发言人两本账：字幕台只持有片段上挂的姓名；正式姓名和职务由会务组的**出席名册**独立持有（独立本地存储）。
- 逐条对账挂起：名册换人或改写法后按挂名重新对账；名册查无或已停用的待确认片段自动**挂起**，挂起期间不能确认进直播区，已上屏片段照旧保留并标注。
- 会务组确认：挂起的挂名可在名册面板中「补录为正式发言人」或「改挂到接手人」，确认后片段自动解除挂起。
- 失败隔离：会务组侧重领名册失败只重试名册那一份，字幕稿不做任何改动。
- 旧数据升级：没有发言人来源的旧稿按现有片段回填 `speakerKey` 并立即对账，回不上的片段（含已上屏）单列迁移报告。
- 术语快捷替换：规则可限定发言人，可一键应用到当前字幕，并记录使用次数。
- 直播确认：使用 `⌘/Ctrl + Enter` 确认后进入直播时间线，支持导出 SRT。
- 离线校正：断线后仍可继续修改和确认（含名册改动），确认内容进入离线发件箱。
- 顺序合并：恢复连接后按序号和开始时间排序合并、补一遍发言人对账，并重新检查重复和过期内容。
- 异常提示：重复片段、等待超过 90 秒的过期片段、最长等待时间和队列积压都会明确展示。
- 长时使用：提供深色值守界面、14–28px 字幕字号调整和清晰的键盘焦点。
- 键盘操作：`Alt + J/K` 切换片段，`⌘/Ctrl + 1–4` 插入常用标点，`⌘/Ctrl + Z` 撤销，`⇧⌘/Ctrl + Z` 重做。
- 本地持久化：所有修改、术语规则、连接模拟状态和界面字号保存在 `localStorage`。

## 技术栈

- Lit 3
- TypeScript 5
- Carbon Web Components 2
- Carbon Styles
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。模拟队列每 5 秒自动更新，可用界面中的“模拟断线”和“恢复并合并”演示离线流程。

名册对账演示：初始名册只有主持人/主讲人/嘉宾三人，第 009 段「现场提问」查无名册即被挂起，确认按钮禁用；右侧「出席名册」面板可补录、改别名、停用换人，也可用「发第二版（换人/改写法）」演示陆明→韩肃换届后挂「主讲人」片段的批量挂起，以及「模拟领取失败」演示失败隔离。模型层断言见 `scripts/check-model.ts`（需先 esbuild 打包到临时文件后以 Node 运行）。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1011 .
docker run --rm -p 10011:80 sologsb-1011
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10011`。
